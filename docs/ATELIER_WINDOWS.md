# 藏书阁 · Atelier Edition（Windows x64）

完整解压 ZIP，打开其中的 `JMComic` 文件夹。第一次建议先双击 **Preview-Atelier.cmd**：它使用当前用户本地应用数据目录下独立的样书库，在本机随机端口展示真实页面。只有“预览”使用合成书目；搜索可试“海岸”，也可以到资源库查看只有 CBZ 的《雨夜钟楼与旧书店》。页图在本机生成，ZIP、PDF 与已发布页来自演示实例。预览没有接入真实上游下载，关闭其控制台或按 Ctrl+C 可退出。

**JMComic.exe** 打开普通实例。Windows 不需要安装 Node、Python 或额外字体。设置和原来的命令行接口继续使用相同数据库；如首次尝试原有书库，先正常退出旧程序，按 `WINDOWS_VNEXT_REVIEW.md` 用完整备份恢复到新目录，再 `JMComic.exe launch --home "副本绝对目录"`。不要让旧 EXE 打开升级后的 v5 实例。

四色主题用于书斋、传输、阅读和设置。主题持久保存在当前实例；可在同一个服务访问 `/ui/classic` 对照经典版，用 `/ui/atelier` 切回来。切换界面只改变当前浏览器的选择，不会复制或移动书。也可在启动前设置 `JMCONSOLE_UI=classic` 作为尚未选择过界面的浏览器默认值。

下载完成和整册整理是两步：同册任务 A 暂停后，B 的已发布章节可以先读和导出；清除任务记录不删除书库成果。归档被占用优先重试整理。设置只提交有变化的字段；重试 `0` 表示请求一次，代理清空表示后续新建客户端直连。演示实例还可在藏书阁页面底部点「退出样书预览」正常关闭；关闭标签页本身不会停止服务。

如果旧版在传输中心提示「下载路径过长」，新版会在较深的 Windows 便携目录里缩短临时写入路径，保留原有书库、任务编号和目录记录。**用新版打开旧实例**：先从旧版控制台按 Enter 正常退出，完整解压新版到另一个目录，再在新版目录中运行 `./JMComic.exe launch --home "旧 JMComic.exe 所在文件夹的绝对路径"`。核对显示的目录并输入 `y`。在传输中心对失败记录点一次「重试」即可；同一本书已有排队或运行中的相同任务时，先看该任务的进度。不必删除旧任务或移动书库，也不要只把新 EXE 复制到旧 `_internal` 旁边。若根目录本身过深，连最短的成品路径也放不下，仍须按备份恢复说明改用较短位置。

开发者：`frontend/` 内 `npm ci`、`npm run build` 重建 Vue 3 / TypeScript / Vite 传输统计；生成的本地文件在 `static/atelier-ui/`，对应许可证随文件分发。其余页面保留 Flask 模板和原有客户端 API，不需要 CDN。切换经典页与更换程序版本是不同操作；后者的备份、实例选择与退出步骤见 `README-Windows.md`。
