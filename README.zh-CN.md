# JMComic 本地下载控制台

[English](README.md) | [简体中文](README.zh-CN.md)

一个面向 Windows 的本地漫画管理工具：在浏览器里搜索、收藏、管理下载、阅读本地图片或 CBZ/ZIP，以及导出 ZIP/PDF。
界面为中文，程序和数据运行在自己的电脑上。

这是 Python 应用，不是浏览器扩展或在线托管服务。仓库不包含漫画内容和个人凭据。
请仅访问、下载和使用你有权使用的内容。

## 环境要求

- Windows 10/11。
- Python 3.10–3.12；本轮本地验证环境为 Python 3.12。
- 首次安装依赖需要联网；搜索、在线观看、检查更新和下载也需要能够访问上游服务。
- Git 仅在使用克隆和拉取更新时需要；也可以下载仓库 ZIP 后解压运行。

项目使用自己的 `.venv` 虚拟环境，不需要把运行依赖安装到系统 Python 中。

## 第一次使用

### 1. 获取代码

使用 Git：

```powershell
git clone --branch main https://github.com/MK6657/jmcomic-local-console.git
cd jmcomic-local-console
```

也可以在 GitHub 的 **Code → Download ZIP** 下载并解压。功能以当前分支的代码为准；未合并的 PR 不会出现在 `main` 中。

### 2. 启动

双击项目目录中的 **`start.bat`**。

脚本会进入项目目录、按需创建 `.venv`、安装或检查运行依赖，然后启动服务并打开浏览器。
首次启动可能需要等待依赖安装完成。

通常访问 [http://127.0.0.1:5000](http://127.0.0.1:5000)；端口被占用时会尝试 5001–5003，以启动窗口显示的地址为准。
程序不会为了占用端口而结束其他软件。

保留启动窗口。按 **回车** 或 **Ctrl+C** 可以停止该窗口启动的服务；如果只是打开了之前已运行的服务，窗口不会接管它。

### 3. 检查设置并下载

1. 打开 **设置**，按自己的网络需要配置代理。
2. 首次使用建议保留默认值：**不整理目录**、**跳过已存在的文件**开启、自动打包和删除原图关闭。
3. 在 **搜索** 中查找漫画，打开详情后选择下载全部或指定章节。
4. 在 **下载管理** 查看队列、进度、失败原因，进行取消或重试。
5. 下载后的内容在 **资源库** 中管理；只想留作以后观看的内容可以加入 **收藏**，不必下载。

默认开启“检查新章节”，它会联网查询已下载漫画的章节列表，但不会自动下载。暂时不想联网检查时，可在设置中关闭。

### 使用命令启动

在项目目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launcher.py --wait
```

不自动打开浏览器、直接查看服务输出：

```powershell
.\.venv\Scripts\python.exe app.py
```

已安装依赖后，可双击 `launcher.pyw` 无窗口启动；`launcher.py` 不带 `--wait` 也会在后台运行。
如需结束后台服务，先根据 `runtime/data/flask.json` 核对本项目的进程 PID，再结束对应进程。

## 主要功能

### 搜索、收藏与资源库

- 搜索漫画、查看详情和章节；收藏不等于下载。
- 收藏与资源库支持关键词、下载状态、排序和分页；资源库可点击作者名筛选。
- 状态顺序为：**可离线阅读 → 进行中 → 失败 → 下载过 · 本地文件不可用 → 未下载**，另有“全部”。
- “未下载”用于从未下载过或已取消的收藏；下载失败和本地文件丢失各有自己的分组。
- 页面上的阅读按钮按当前本地文件情况决定入口：有可读内容时打开本地阅读，否则转到在线观看。

**“已下载内容 · 可离线阅读”只表示本地有可读内容，不保证整部或全部章节已下载。**
只有本地文件和当前章节列表足以确认时，详情页才显示“部分章节已下载 · M/N 话”。
本地文件不可用时会说明原因，例如“文件已删除”“压缩包损坏”或“压缩包无可阅读图片”。

### 本地阅读与在线观看

- 支持 **连续滚动** 和 **单页翻页**，可跳页、切换模式并记住页码；单页模式有缩略图和翻页按钮。
- 可直接阅读本地散图，以及只剩 CBZ 或本程序 ZIP 的漫画；不需要先恢复成散图。
- 本地散图与包内页面可共同构成阅读内容；损坏或无图片的压缩包会明确报错。
- 阅读工具默认收起，可轻触图片或空白处、按 **M** 或使用页首“阅读工具”打开，按 **Esc** 收起。
- 动图页保存为动画 WebP，本地阅读保留动画；PDF 导出使用第一帧。
- **在线观看**按需获取并解码图片，不建立下载任务、不加入本地资源库；最近看过的图片会缓存在 `runtime/cache/online/`，上限 512 MB。

### 检查新章节与两种批量下载

**自动检查**默认开启：启动后约 5–7 分钟开始，只检查本地有可读下载内容的漫画，一次一部，通常每部一天一次；两次自动检查之间至少隔 2 分钟，有下载正在进行时等待，失败后逐步放慢。

检查只获取章节列表，**不会自动下载**。只收藏、没有下载的漫画不检查。
“有新章节”只在检查确认后显示；下载时主动没选的旧章节不算新章节。功能启用前已有的下载，首次检查会先建立章节基准。
关闭自动检查后，仍可在详情页点 **立即检查**；**选中这些章节**只勾选复选框。

| 入口 | 下载范围 |
| --- | --- |
| 资源库 → **下载新章节** | 本地已有下载内容的漫画中，检查确认的新章节；包括未收藏的漫画，不整部重下 |
| 收藏 → **下载未下载的收藏** | 从未下载过、或已取消下载的收藏，按整部加入队列 |
| 收藏 → **下载选中的收藏** | 对勾选的收藏应用上述“未下载”规则，其他状态会说明跳过原因 |

这些入口都先显示漫画、章节、数量和范围，**确认后才入队**，确认时重新核对清单，避免重复排队。
失败的任务应在下载管理重试；已有部分内容、文件已删除等情况不会被“下载未下载的收藏”整部批量下载。
需要补齐以前未选的旧章节时，请到详情页自行选择。

### 快捷导航与位置记忆

- 普通页面右下角的指南针提供首页、搜索、下载管理、收藏、资源库、设置，以及 **返回 / 到顶 / 到底**。
  鼠标悬停展开，点击可固定展开；阅读和预览页使用自己的阅读工具。
- **返回**按本标签页内记录的应用页面逐步后退；新标签页或没有可返回记录时不可用。
  浏览器不支持 Navigation API 时，该快捷返回也不可用，可使用浏览器自身的后退。
- 顶部或快捷导航中的 **搜索 / 收藏 / 资源库**保留本标签页的关键词、筛选、排序、页码和滚动位置，最长 12 小时。
  搜索恢复的是此前的结果快照，想获取新内容时自行刷新或重新搜索。
- 搜索页按 F5 时，30 分钟内可复用结果，超过后重新搜索；直接在地址栏输入 `/search` 则打开新的搜索页。
- **设置 → 界面操作**可开启“点击资源库卡片空白处打开详情”，默认关闭；封面、标题和“详情”按钮始终可用。

### 队列、打包与目录整理

- 可设置并行任务、图片/章节并发、超时、重试和定时下载。
  定时下载限制队列任务的**开始时间**，程序需保持运行；它不会自行收藏漫画或创建下载任务。
- 支持 ZIP/PDF 导出，以及可选的 CBZ/ZIP 自动打包。PDF 遇到坏图会明确失败，不输出缺页 PDF。
- 自动打包会保留旧压缩包中的章节；不能安全完成时保留原文件。
- **“打包后删除原图”会删除源图片**，默认关闭。开启前确认自己确实需要，并保留备份。
- 下载目录固定为项目内的 `downloads/`；“下载后自动整理目录”默认为 **不整理**。

可选的目录整理方式：

| 方式 | 行为 |
| --- | --- |
| 不整理 | 保留漫画及章节目录结构 |
| 按作者整理 | 整个漫画目录移入作者目录；文件被占用时重试，仍失败就完整留在原位置，下次下载该漫画后再整理 |
| 扁平化 | 页面移至漫画目录下，以章节标识和页号区分，重新下载时识别已有页面 |

章节按章节 ID 识别。上游只改章节标题时会复用已有章节目录，目录可保留旧标题。
不整理模式下只剩压缩包时，再次下载仍可能重新获取原有图片。
目录整理不是旧数据清理工具：旧版本已经产生的重复目录或页面不会自动合并或删除。
旧扁平化数据、损坏或被占用的旧文件，以及散图与旧压缩包混合的少数情况，仍可能重新下载、显示重复页或影响页序；压缩包的存在检查也不等于逐页完整性校验。
首次使用可保持“不整理”；调整模式前建议备份已有内容。

## 更新已有安装

更新前先停止服务并备份个人数据。使用 Git 的安装，在项目目录执行：

```powershell
git status --short
git switch main
git pull --ff-only origin main
```

如果存在自己修改过的项目文件，请先保留修改并处理 Git 提示，不要强制覆盖。
更新后重新运行 **`start.bat`**，它会检查依赖，并根据源码内容识别、停止本项目已核实的旧服务，再启动新版；中断的下载会在启动时重新排队。
若源码未变，则复用已有服务；仅静态 CSS/JS 更新通常无需重启，刷新页面即可。

使用 ZIP 的安装，可先停止自己的服务、备份数据，再更新项目代码；保留原有 `downloads/` 和 `runtime/`，不要用他人的个人数据库覆盖。
朋友首次安装应各自创建运行环境，不需要复制测试机器的 `.venv/`、`runtime/` 或 `downloads/`。

## 本地数据与隐私

| 路径 | 内容 |
| --- | --- |
| `downloads/` | 下载图片及自动打包的压缩包 |
| `runtime/data/app.db` | 设置、收藏、任务、历史及检查记录 |
| `runtime/cache/` | 本地缓存，包括在线观看图片 |
| `runtime/logs/` | 应用、错误和启动日志 |
| `.venv/` | 本机 Python 虚拟环境 |

上述个人数据和环境不随仓库提交。备份个人资料时保留 `downloads/` 和 `runtime/data/`；操作前先停止服务。
ZIP/PDF 导出先在系统临时目录生成，再由浏览器保存到你选择的位置，不会自动存入项目的 `downloads/`。

服务仅监听 `127.0.0.1`，**没有用户认证**，不要通过公网端口转发、公共反向代理或共享服务器暴露。
代理认证信息保存在本地数据库中；日志也可能包含搜索词、标题和本地路径，请勿直接公开分享。
设置导出会排除代理配置，重新导入不会覆盖目标机器的代理；手工编写的设置文件仍可能包含代理，应检查后再分享。

### 日志与归档

- `app.log` 和 `error.log` 每天或超过 20 MB 时归档，文件名为 `<名称>.YYYY-MM-DD[.N]`。
- `launcher.log` 由启动器在每次启动前归档（超过 5 MB 或最后写入于更早的日期时）；服务持续运行期间会继续写入当前文件，
  不按应用日志的 20 MB 规则轮转。
- 历史日志保留 7 天；启动及后台维护还会按 100 MB 的总量目标，从最旧的历史日志开始清理。
  当前活动文件不会直接删除；文件被占用时保留并等待后续清理。

## 常见问题

- **双击后提示找不到 Python：**安装受支持的 Python 并加入 PATH，再启动；也可用上面的命令手动创建环境。
- **安装依赖失败：**查看启动窗口中的 pip 错误，检查网络和 Python 版本；运行依赖安装使用的是 `.venv` 内的解释器。
- **服务启动失败：**查看 `runtime/logs/launcher.log`，或直接运行 `app.py` 查看错误。
- **搜索、在线观看或下载失败：**检查网络、代理和上游可用性；离线测试通过并不代表上游此刻可访问。
- **页面显示旧版：**再次运行 `start.bat`，然后刷新浏览器，确认地址是启动窗口显示的端口。
- **查看日志：**打开 **设置 → 日志与诊断**，可搜索、按请求编号筛选并打开日志目录；日志自动归档和清理。
- **其他系统或 EXE：**打开文件夹和单实例锁含 Windows 专用实现；仓库中的 `build.spec` 不代表已提供或验证可用的 EXE 发行版。

## 开发与隔离测试

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tests/check_startup.py
.\.venv\Scripts\python.exe -m compileall -q app.py launcher.py core routes
Get-ChildItem static/js/*.js | ForEach-Object { node --check $_.FullName }
```

JS 语法检查需另外安装 Node.js；运行应用本身不需要 Node.js。项目没有 `package.json` 或 npm 构建流程。
默认回归测试使用临时数据库和目录，不执行真实搜索或下载；`check_startup.py` 使用临时实例检查本地启动及端口回退。
`tests/conftest.py` 排除的旧脚本可能联网或修改数据，不应对个人实例直接运行。

本轮本地验证（2026-10-22，应用源码基线 `94390d1`）：Python 3.12 环境下 **1150 项通过、2 项跳过**，编译检查和 16 个 JavaScript 文件的语法检查通过。
跳过项需要 Windows 文件符号链接权限；目录联接相关测试已通过。这些结果针对上述代码版本，不能代替真实网络和下载测试。

需要在浏览器查看可丢弃的测试数据时：

```powershell
.\.venv\Scripts\python.exe tests/ui_reader_fixture.py --port 5010
```

访问 [http://127.0.0.1:5010](http://127.0.0.1:5010)。此夹具使用临时数据并替换上游与下载执行，不代表真实网站、网络或真实下载已经验证。
