# JMComic 本地下载控制台

[English](README.md) | [简体中文](README.zh-CN.md)

面向 Windows 的 jmcomic 本地浏览器控制台，提供搜索、下载队列、实时进度、
收藏、资源库、本地图片阅读和压缩包/PDF 导出。程序界面目前为中文，说明文档提供中英文。

这是一个**本地 Python 应用**，不是浏览器扩展，也不是在线托管服务。
请仅访问和下载你有权使用的内容。仓库不包含下载内容、个人凭据或第三方参考项目。

## 环境要求

- Windows 10/11，Python 3.10–3.12；本次维护使用 Python 3.11 验证。
- 安装依赖需要联网；搜索、下载还依赖上游服务和本机网络状况。
- 使用项目独立虚拟环境，避免与 Hermes 或系统 Python 的依赖互相影响。

## 快速启动

克隆或解压仓库后，双击 **start.bat**。脚本会切换到项目目录，按需创建 `.venv`，
安装或检查全部运行依赖，再启动服务并打开浏览器。首次运行需要 PATH 中能找到 `python`。

保持启动窗口打开，按 **回车** 或 **Ctrl+C** 可停止该窗口启动的服务。
若识别到已运行的本项目服务，只会打开它，不会接管或停止已有进程。

也可以在项目目录打开 PowerShell 执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launcher.py --wait
```

希望直接查看服务输出、不自动打开浏览器时：

```powershell
.\.venv\Scripts\python.exe app.py
```

访问 [http://127.0.0.1:5000](http://127.0.0.1:5000)。端口被占用时，服务会尝试
5001–5003，以终端显示的地址为准。启动器不会为了释放端口而强杀其他程序，
且会核对服务身份和 PID。再次运行 start.bat 时会复用正在运行的服务；若 `app.py`、`core/`、
`routes/` 或 `templates/` 与它启动时的文件不同（按内容比较，覆盖复制进来的更新也算），则只停止这个已核实的旧服务
并启动新版本（中断的下载会在启动时重新排队）。
只改静态 CSS/JS 无需重启。

安装依赖后，可双击 `launcher.pyw` 无窗口启动。`launcher.py` 不带 `--wait`
时同样在后台运行。停止后台服务前，请核对 `runtime/data/flask.json` 中的 PID
确实属于本程序，只结束对应进程。

## 功能与设置

- 搜索卡片新增**阅读**按钮，进入本地连续向下滚动的阅读页；支持分批加载、跳页、失败重试和会话内阅读位置记忆。
  不会自动下载；未下载的漫画点**阅读**会转到在线阅读（见下文）。
  标题随页面滚走，返回和跳页默认隐藏；轻触画面/空白处或按 M 显示，Esc 收起，也可用页首“阅读工具”按钮唤出。
  页码与章节说明只在第一页显示；隐藏工具内还有一键到顶、到底的小图标。
  支持单页翻页与连续滚动互切并保留页码；单页缩略图完整等比显示，带页码、左右浏览按钮，跳到后续页会自动加载对应缩略图。
  单页模式下整页图片与翻页按钮在桌面端一屏内显示（缩略图移到下方）；翻页时保留当前图直到下一张就绪，并预读下一页。
  带 Alt/Ctrl 的方向键交还浏览器，Alt+← 仍可后退。
- 顶部导航的**搜索 / 收藏 / 资源库**会回到本标签页上次离开时的样子（12 小时内）：同样的搜索结果和页码（直接显示，不重新搜索），
  同样的筛选、排序和页码，并回到列表里看到的位置——为了点导航先滚回页面顶部也不影响。直接在地址栏输入 `/search` 仍是全新的搜索页。
- 可离线阅读的漫画在各页面都标“✓ 已下载内容 · 可离线阅读”：搜索结果封面角标、详情页、资源库卡片、收藏和下载管理
  （另有“预览”）。判定标准：最近一次下载的目录仍在且有页面图片（或能读的 CBZ / ZIP）；这不代表整部漫画都已下载。
  本地章节目录和刚取到的章节列表能证明只下载了部分章节时，详情页另标“部分章节已下载 · M/N 话”。
  目录被删或被清空显示“文件已删除”。
- **检查新章节**（设置页“检查新章节”，默认开）：本地有已下载内容（“已下载内容 · 可离线阅读”，包括只下载了部分章节的、
  只剩 CBZ / ZIP 的）的漫画在后台慢慢检查：一次只查一部，每部大约一天一次，两次之间至少隔 2 分钟，有下载在进行时先等。
  一次检查只取一次章节列表，**从不下载任何内容**。“新章节”指你下载之后上游新出的章节，下载时没选的章节不算；
  更新前下载的漫画第一次检查只记下现有章节。已确认的新章节在资源库、收藏和下载管理显示“有新章节 · N 话”；
  详情页显示检查状态、在章节表里标“新”，并有**立即检查**（关闭自动检查后也能用）和**选中这些章节**
  （只勾选这些章节，下载仍要点**下载选中章节**）。
- **批量下载**（都由你点击开始，并先确认）：资源库的**下载新章节**只下载本地已有下载内容的漫画里检查确认过的新章节
  （收藏和没收藏的都算，从不整部下载）；收藏页的**下载未下载的收藏**整部下载从未下载过、或下载被取消的收藏。
  下载失败的留在「下载管理」的「失败」里重试，已有已下载内容的（包括只下载了部分章节的）不会包含。
  两者都先列出这次会下载的漫画、章节和范围，以及其余漫画不下载的原因，确认后才加入下载队列；确认时服务端重新核对清单，
  已在下载队列中的漫画不会重复建任务；开启了“定时下载”时，任务照常只在时间段内开始。
  收藏选择栏的**下载选中的收藏**对选中的行用同一规则。
  详情页“立即检查”确认的新章节还不在章节表里时，章节表就地刷新，保留勾选和滚动位置。
- 搜索结果、资源库、收藏和下载管理（已完成与失败的任务）中每部漫画都有**阅读**按钮：已下载的打开本地文件（实心按钮、书本图标），
  否则转到在线阅读（描边按钮、地球图标）。点击时才判断，页面打开后文件有变化也能去对地方。
  详情页保留常驻的**在线观看**，下载完成后再多一个**阅读**。
- 收藏可按下载状态筛选，按最新/最早添加、标题、作者或下载状态排序；资源库状态分组与之一致，并支持按作者排序、
  点作者名只看该作者。筛选与排序保存在地址栏中，刷新、返回都不会丢失。
- 漫画详情页新增**在线观看**按钮（每个章节行也有入口），打开同一个连续阅读页但不下载：页面由本程序按需经自身连接
  （与下载相同的代理和域名）获取并解码，最近读过的页面缓存在 `runtime/cache/online/`（上限 512 MB，最久未读的先淘汰，
  `POST /api/system/clear-cache` 可清空），不写入资源库。取不到的页面在设置页的“超时”（至少 15 秒）内换用其他图片域名
  重试，到时才报错；还在接收的慢速页面不会被提前中断。本地阅读仍只读本地文件。详情页封面与信息卡片垂直居中对齐；封面保持原比例，
  宽不超过列宽（最多 300px）、高不超过 400px，小图不放大。
- 从详情或阅读页返回，会恢复搜索关键词、排序、页码、结果和滚动位置。
  搜索结果仅在浏览器会话／历史状态中缓存：经导航或后退回来最长复用 12 小时；刷新（F5）超过 30 分钟就重新搜索。

- 搜索、详情、下载队列、失败重试、取消、SSE 实时进度。
- GIF 动图页下载时不做解码切片，保存为动画 WebP（文件名仍是 `NNNNN.webp`），本地阅读保留动画，PDF 导出取第一帧。
  旧版本下载的章节里 GIF 页可能被切片或只剩第一帧：之后再下载该漫画时只会重新获取这些 GIF 页（即使开启“跳过已下载”）。
- 章节按章节 ID 认，不按标题认：上游给一章改了标题、章节 ID 没变时，再下载这一章（下载全部或只选这一章，三种整理方式都一样）
  沿用原来的章节目录（目录保留旧标题），“跳过已下载”不会再取一遍（不整理、只剩压缩包的漫画和以前一样重新下载全部图片），
  阅读器里也不会出现两次；上游加了页只下载加的页，放进这个目录。
  更早的版本在改标题后另建过的目录原样留着（它的页照旧显示）；按上游现在的标题命名的那个照旧优先（它缺的页会下载进去，这一章会多出来），都不是现在的标题时才用页数多的那个。
- 整理下载目录从不“复制一份再删原来的”：按作者整理把整个漫画目录一次改名，目录里有文件正被别的程序
  （杀毒软件、资源管理器预览、看图软件）打开时短暂重试几秒；仍不行就完整留在原处，下次下载该漫画后再整理。
  扁平化的页名是 `<章节目录名>_p<页号>`（如 `第1话__71_p00001.webp`），旧版本从没用过这种名字：重新下载的页只替换它自己的扁平页，
  不会覆盖别的页；“跳过已下载”也认得这些页（散图，或漫画目录里压缩包中的），不论现在选的是哪种整理方式
  （有散图时只看散图：坏了就不算、重新下载这一页，自动打包后这一页总还有一份好图）。
  旧版本扁平化的章节（累加序号页名）只在整章完整时认得；否则重新下载：和这一章某张旧页逐字节相同的新页直接丢掉
  （每张旧页只顶一张新页；旧文件留着；以后下载可能再取一次，旧页读得出来时不会出现两次；它自己的新页名散图坏了时改为替换那张坏散图）；
  旧页读不出来（被占用、坏了）时新页照常按新页名保留，这一页会出现两次（自动打包后一直如此）。
  不同的（如旧版本切片的 GIF 页）按新页名留在旧文件旁边，这些页会出现两次。
  整理从不改名、覆盖或删除旧文件和压缩包。被占用、移不动的页留在章节目录里，下次下载该漫画后再整理：这期间它排在这一章扁平页的前面
  （漫画目录里已有它的一份——替换不了的扁平页或它重复的旧页——时会出现两次），自动打包也等它整理好再做。
  章节目录里坏了的页（`NNNNN.webp`）在下载这一章时总会重新下载。
  已知的窄情况：更早版本留下的重复旧页名恰好凑够一章现在的页数时，这一章会被当成完整；压缩包里的页按压缩包目录算已下载，不逐页重读；
  整理时压缩包正被别的程序占用（整章完整、开着“跳过已下载”时还要检查章节时也被占用），旧章节的页会重新下载、和旧页一起打进包；
  还留着旧页名的章节里，旧页名的页总排在新页名的页前面：只按旧页名留着的页可能排到它前面某一页的新页名之前
  （旧页缺了一张、上游在前面插了页、或重新取回的 GIF 页不是这一章最后一页时）。
- 收藏清单、下载资源库、本地图片阅读器。
- ZIP/PDF 导出、可选的 CBZ/ZIP 自动打包。
- 定时下载、并发数、超时、重试次数、代理设置。
- 设置导入和导出：**导出不包含代理配置**，重新导入也不会覆盖目标机器的代理。
  手工制作的导入文件仍可包含代理，分享前务必检查。

如需代理，在设置页填写。代理认证信息会保存在本地 SQLite 数据库中，不要分享数据库。
下载目录固定为项目内的 `downloads/`。开启“打包后删除原图”会删除源图片，
没有明确需要时请保持关闭。

## 数据与隐私

| 路径 | 用途 | 是否提交 |
| --- | --- | --- |
| `runtime/data/app.db` | 设置、任务、历史记录 | 否 |
| `runtime/logs/` | 应用、错误和启动器日志 | 否 |
| `downloads/` | 下载文件与导出内容 | 否 |
| `.venv/`、`.worktrees/` | 本地环境和工作树 | 否 |
| `参考项目/`、`docs/reports/` | 参考仓库和历史本地审计资料 | 否 |

服务仅监听 `127.0.0.1`，没有用户认证。不要通过端口转发、公共反向代理或共享服务器
暴露给其他人。日志即使对认证信息脱敏，也可能包含关键词、标题和本地路径，不宜公开分享。
`runtime/logs/launcher.log` 保存启动及后台输出；启动器每次启动前会将其归档，
与应用日志一样保留 7 天。

### 日志与排查

- **设置 → 日志与诊断**（`/settings#logs`）可查看最近的问题（警告和错误）或全部记录，支持搜索、按请求编号
  （request id）筛选，并可一键打开日志文件夹。在线阅读中加载失败的页面会直接链接到这里。
- `runtime/logs/` 中：`app.log`（INFO 及以上）、`error.log`（警告和错误）、`launcher.log`（启动输出）。
  `app.log` 和 `error.log` 每天或超过 20 MB 时归档为 `<名称>.YYYY-MM-DD[.N]`（N 越大越新）；`launcher.log`
  由启动器在每次启动前归档（超过 5 MB 或最后写入于更早的日期时），服务持续运行期间会一直写入同一个文件。
- 重复消息自动合并：第一条完整记录，之后同类消息只计数，最后写一行 `↑ 同类消息 N 次已合并（…）`。
  只有写成 `job_id=` / `album_id=` / `photo_id=`（任意 `…_id=`）的编号会分开记录；其他数字（包括请求路径里的编号，
  如 `/api/online-img/<photo_id>/<n>`）和页码一样按同类合并。合并了多个请求的摘要会列出这些请求编号，按请求筛选仍能找到。
- 超过 7 天的日志文件在启动时和每天自动删除，总大小上限 100 MB。静态资源和健康检查等例行请求不再记录。

## 开发与验证

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tests/check_startup.py
.\.venv\Scripts\python.exe -m compileall -q app.py launcher.py launcher.pyw core routes tests
```

默认回归测试使用临时运行目录和数据库，不执行真实搜索、下载。
`tests/conftest.py` 列出的旧脚本在导入时就会联网或修改数据，因此不参与默认收集。
不要对个人实例运行这些脚本；需要调查时，请使用可丢弃的项目副本。

`check_startup.py` 另做本地 HTTP 检查：启动和停止临时数据实例，验证端口回退，
不会访问上游服务。

项目没有 `package.json`，因此不提供 npm lint/typecheck/build 脚本。
`build.spec` 是保留的 PyInstaller 打包方案，不代表本次已验证 EXE 产物。

## 故障排查与限制

- 启动失败：查看 `runtime/logs/launcher.log`，或直接运行 `app.py` 获取报错。
- 缺少依赖：使用同一个 Python 解释器安装完整的 `requirements.txt`。
- 搜索失败：检查网络、代理和日志；`core/settings.py` 中的上游域名可能随时间失效。
- 离线测试通过不代表上游联网、真实下载或 EXE 打包已经验证。
- 打开文件夹和单实例互斥锁包含 Windows 专用实现，不保证其他平台可直接运行。

### 缓存与查询优化

- 同一详情的并发请求共用一次查询；缓存有效期生效，调用方不能意外修改缓存，损坏缓存会重新获取。
- 清除缓存同时处理内存和 SQLite 详情缓存，不删除个人记录；清理前的后台请求不会重新填入旧缓存。
- 测试确认：25 条已下载资源的一页列表只使用 1 个数据库连接、4 条 SQL；文件存在状态不再延迟五分钟更新。
- 修复排队中筛选、重复标签筛选、冷门标签补全，并增加分页排序的稳定次序。
- 同专辑等待任务不再挡住后续其他专辑；重复批量同步返回忙碌提示，归档缓存淘汰增加并发保护。

验证：137 项测试通过，1 项因 Windows 文件符号链接权限跳过。
